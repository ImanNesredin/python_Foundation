# Python Mini Projects Collection

This repository contains three basic Python projects designed to strengthen core programming skills such as loops, functions, conditionals, and problem-solving.

---

## 📌 Project Overview

### 🔹 Level 1: Compute Factorial
A program that calculates the factorial of a given number.

**Features:**
- Handles user input repeatedly until exit
- Validates input (no negative numbers or invalid values)
- Uses an efficient iterative approach

**Concepts Used:**
- Functions
- Loops
- Input validation

---

### 🔹 Level 2: Fibonacci Sequence (Pyramid Style)
A program that generates a Fibonacci sequence displayed in a pyramid format.

**Features:**
- Prints sequence line-by-line (pyramid pattern)
- Handles invalid input
- Repeats until user exits


**Concepts Used:**
- Loops
- Sequence generation
- Pattern printing

---

### 🔹 Level 3: Tic Tac Toe Game
A two-player console-based Tic Tac Toe game.

**Features:**
- Players can choose starting symbol (X or O)
- Input validation (no overwriting moves)
- Win detection using all possible combinations
- Clear board display after each move
- Detects win or draw
